# Local specification setup

The ECSS specification PDF is intentionally not distributed in this public
repository. Obtain the document through an authorized source and place it at:

```text
assets/spec/ECSS-E-ST-50-12C-Rev.1(15May2019).pdf
```

Expected SHA-256:

```text
e1732409cfc337c47299742c8d63706c2fd2cb865bc2d079a291cf2147fb364b
```

Without the local PDF, trace metadata, page numbers, source links, test
execution, logs, and waveforms continue to work. Only the **Open PDF page**
action is unavailable.
